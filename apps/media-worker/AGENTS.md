# @wb/media-worker

- ADR-0035：合格原片写私有对象后capture触发原预留一次结算；存储失败不提前结算。后续ASR/字幕/合成异常仅恢复原片，不当作视频生成失败退款；完成发布无第二次收费。

- ADR-0033：processNativeMarketing先读已保存原片；本地ASR产出待核对草稿，ready才烧字幕并保留原声。读存储/识别/合成失败记录issue并重试原素材，禁止调用旧fail退款或模型生成；fixture只用于明确mock作业。ASR三项路径全配、本地模型离线，不在运行时下载。

- ADR-0032：原生营销10秒的字幕持久处理尚未接通，必须在旧renderVideo发布分支前拒绝10秒，不能把计划口播直接烧成已核对字幕。5秒历史路径保持原规则。

- ADR-0026：manifest2字幕只取冻结spokenLines，画外音不成为出镜角色；silent_preview不宣称真实配音同步。营销只在有分类和口播文本时烧录口播字幕，保留原音轨。独占微信stack使用单独媒体队列，与普通模型worker分开；5条预览/15history回放证明mock流程，不证明正式质量。

- 独立Temporal媒体队列，每进程最多执行一个媒体任务，FFmpeg固定线程与超时。
- 先验证/标识媒体，再存私有对象，最后通过server资产发布用例原子记录资产与结算。
- 不加载模型密钥，不直接调用供应商，不写SQL，不调用旧API实现。
- 相同job重复处理返回已发布资产，不重复结算。对象写入与数据库事务分开，允许幂等重试，不宣称跨S3/PG事务。
