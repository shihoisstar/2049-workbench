# @wb/media

- ADR-0035：原生视频可预览检查增加H264视频/AAC音轨要求，与已认可样片一致；未合格前不能触发可预览结算。

- ADR-0033：native-video验证原片10秒附近/720竖屏/有音轨，私有source键按job与sha固定。本地ASR校验源WAV哈希及逐字时序，字幕保留识别原文，不拿计划口播替换；用户确认与账本事务由server处理。

- ADR-0027真实试片发现竖屏ASS缺PlayRes导致字幕溢出；字幕函数必须接实际画幅，固定安全边距与按短边计算字号，营销/漫剧共用。供应商低分辨率样片不得靠上采样作为原生720P验收证据。

- ADR-0026：字幕ASS只用核对后的时序与转义文字，拒绝越界/重叠；compose保留源音轨，或使用哈希正确的PCM s16le WAV，时长超镜头30ms拒绝，不静默截断。TTS请求/资产持久化不属于本包，不把测试音当真实配音；营销和漫剧共用字幕文件生成。

- 只供后端使用：受限下载、FFmpeg处理、S3对象读写/签名。不得导入前端或契约包。
- 下载仅HTTPS，解析并固定公网IP，每次重定向重新验证，限制大小/时间；不得关闭TLS验证。
- FFmpeg只读取本次临时目录的本地文件，限制协议、时长、尺寸和进程超时；失败不得原片直出。
- 对象存储私有。签名URL的账户授权与有效期由调用API先检查；不在普通日志输出URL或密钥。
- 任务/资产/结算事务属于@wb/server，本包不写业务数据库。
