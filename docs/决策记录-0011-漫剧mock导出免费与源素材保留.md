# ADR-0011：漫剧 mock 导出免费与源素材保留

- 状态：已接受
- 日期：2026-10-09

## 背景

逐镜视频已经按镜头生成成本计费。当前导出阶段仅使用本地、确定性的 FFmpeg 合成和 mock TTS，不调用已定价的模型或外部付费服务。现有定价表没有导出或合成价格锚点。

## 决策

当前 mock 导出免费：不创建导出积分预留、不新增导出账本条目、不对导出失败执行积分退款。

导出失败只将 ExportJob 记录为失败，保留已经成功发布的逐镜视频资产、候选、版本和 manifest；不得以失败清理源素材。

## 理由

向用户再次收费会使已为逐镜视频付费的链路产生未经批准的双重收费。没有实测的 TTS/云合成成本前，不能虚构积分价格或退款规则。

## 后果

- #37 实现 FFmpeg 合成、字幕、AI 标识和失败状态机时不接 billing reserve/settle/refund。
- 将来接入真实 TTS 或云端合成且获得稳定成本后，必须新增 ADR，明确导出价格、预留、结算、退款与展示文案后才能收费。
- 这不改变逐镜视频作业既有的计费与退款语义。
