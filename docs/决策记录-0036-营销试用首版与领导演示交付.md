# ADR-0036：营销试用首版与领导演示交付

2026-10-11。负责人明确将“营销视频小范围试用”设为第一版交付目标，必须可正常使用；暂无硬截止，先交微信开发者工具录屏和生成的视频文件。AI漫剧与外围功能本阶段暂停扩展，不删除既有实现。

## 交付口径

剧情带货与探店各完成：输入/素材上传 → 文案确认 → 显示本次试用额度 → 一次提交 → 后台制作/退出找回 → 原声视频预览/字幕核对 → 成片 → 作品找回与电脑文件保存。新增付费调用逐次按明确预算获批；未批准前只做免费开发/演练，不把固定素材回放当实时AI生成。

首版不要求认证完成、微信支付或公开发布。使用本机开发者工具、专用持久试用后端和内测身份/积分；本机试用与公开商用分别报告。试用主入口为创作/作品/我的，暂不展示未交付的漫剧流程。制作独立构建与独立数据目录，不替换或清除原业务数据。

## 已知缺口与最小做法

1. 临时验收栈结束会删除数据，不适合领导随时复看：复用现有PostgreSQL/Temporal/Garage，建立有归属标签的持久本地试用实例；停止保留作品，清理需另外明确操作。
2. 本地S3签名链接为127.0.0.1，Atlas无法访问：原生参考图请求读取本人已确认素材、核验字节长度/SHA-256后使用官方支持的Base64，仍保留图片顺序与现有上传上限。代价是请求体增大；首轮演示复用已有较小PNG，不新增生图费用。
3. 原导航包含漫剧与未完成入口：营销试用构建只列创作、作品、我的及制作进度，沿用已有页面，不另造前端工程。
4. 真实运行必须受本轮批准的调用次数/预算限制；同一任务不重复POST，未知结果停下核对。录像可缩短真实等待，但应标注剪辑；不伪造结果或宣称公开上线。

## 认证与录屏

当前可录制开发者工具中的完整操作。官方测试号文档明确提供开发测试及真机预览能力：[微信开放文档](https://developers.weixin.qq.com/miniprogram/dev/devtools/sandbox.html)。本次交付无需先断言用户现有账号的体验版/发布权限；这些必须在其后台核实。

本机前提：开发者工具已登录并能打开项目，Node/pnpm/Docker与媒体工具可运行，Atlas账号在本机安全配置，网络可达供应商，本地API/存储和后台进程保持运行。开发者工具文件保存不等于手机相册验收，录屏与讲稿必须说明。

领导视频建议3–5分钟：说明试用环境与本次范围；带货完整流程；探店另一条成片；字幕与作品恢复；列出已完成/待上线事项。原始等待录屏保留，汇报版可明确标注“生成等待已加速”。最终提供两条MP4、操作说明、验收记录，不用测试数量代替产品演示。

本决策本身不授权新付费、Git提交、生产发布或旧库迁移。
