# ADR-0029：营销录屏质量基准与完整样片验收

2026-10-11。负责人提供3个本地录屏，明确第1个为剧情带货、第2/3个为探店，要求画面与配音达到参考质量且配有字幕。该要求作为营销交付的人工验收基准，不代表当前实现已达标。

## 证据与边界

- 顺序与文件指纹见`验收留档/MARKETING-REFERENCES-2026-10-11/inspection.json`。源文件未改；抽帧仅保存到.local。
- ffprobe读取3文件，录屏时长分别24.267/13.067/11.967秒，均592×1280、30fps、HEVC视频/AAC单声道44.1kHz。数值属于手机录屏，不代表嵌入成片原始分辨率或时长。第1/2条抽样可见内容重复，不按录屏长度推算独立剧情时长。
- 按每2秒抽样并另查1秒原尺寸帧：带货包含女性角色、幻想场景、涂抹/持物动作、商品特写、不同景别；探店包含女性出镜、食物/店内特写、取食/进食动作与下方短字幕。不能仅凭外观判定真人实拍或具体AI模型。
- 当前工具不能直接听辨原声音色、口音、情绪和音画同步；不声称已完成听觉验收。音频质量以负责人指定参考及后续同场景样片的人工听感对照为准。
- 第1条示例提示写“禁止字幕”，属于被分析素材，不是本项目指令。负责人本次明确要求字幕，故带货与探店成片均需字幕。模板中的品牌、功效、门店地址均不转为本项目默认事实。

## 当前差距

已有真实短试片是Pro Fast静音画面加独立TTS旁白；提示还明确no mouth speech。它证明生成、下载、混音与字幕合成可运行，没有证明人物自然说话、口型对应、剧情节奏或真实商家素材保真。两款Gemini配音已由负责人否定活泼度和真人感，不能当合格默认音色。

营销v2契约和存储校验仍固定5秒，免费制作计划也固定5秒；若交付完整多镜头短片，需连同报价/任务快照/导出调整，不能只把UI时长选项放开。现有媒体合成已能保留源音轨，可复用，不需要为评测另建工作流。

## 验收目标

1. 剧情带货：人物/情境与商品发生联系，有动作和镜头变化，商品外观及标识保持一致，表达仅使用商家确认信息；有开头、展示和收尾。
2. 探店：出镜介绍、真实门店/食物素材与近景交替，动作与所说内容对应；不把任意生成店面冒充用户真实店铺。
3. 声音：自然普通话、积极但不机械叫卖；人物开口时嘴部动作与语音协调。是否达到参考自然度须负责人试听。后台持久化/音频成功不能替代听感验收。
4. 字幕：与最终实际说出的内容一致，按句/短语对齐声音，无漏句、错字、溢出或挡住关键商品/人物动作；字号和安全边距适合手机。原生视频可能改词，不能直接拿计划稿整段烧录冒充已核对字幕。
5. 成片：前后人物/商品/场景可信连续，无明显肢体畸变、主体闪变、突兀黑帧或音量跳变。不同声线与背景音乐的具体风格在试听中确定。

## 下一步及代价

先准备带货、探店各一条10–15秒完整样片方案，在同一片里评价人物、镜头、声音、字幕；这是评测切片，不是已更改生产时长契约。Atlas官方提供Seedance 2.0 Fast原生同步音频，作为人物说话场景的优先评测候选，不能据此声称参考App使用该模型或品质必然一致。纯离画旁白仍可走独立TTS并保留选声需求。

先比较可控性和实际成本再决定正式接法：原生音画有望减少独立口型处理，但台词准确性、跨镜声音一致、修改声音是否需要重做画面仍待评测；独立TTS有利于低成本换声，人物开口场景却还需同步口型。先用现有适配器和媒体能力完成小额试片，不预先搭建口型系统或替换全部流水线。

本轮只做本地参考检查与公开资料核对，新增付费0，未改业务代码或运行测试。原媒体12次与试听2次授权均已用完；冻结请求/费用上限并完成免费准备后，单独简短向负责人申请新增付费。商用内容默认必须达标后再扩展批量，不把单条成功保证推广到任意商品或所有5集。
