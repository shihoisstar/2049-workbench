# ADR-0033：原声营销字幕核对与原视频恢复

2026-10-11。承接负责人认可的探店、剧情带货原生音画样片及“继续”授权。本轮不新增付费请求、不开放真实受理，不改变“新增付费先确认”。

## 原有路径的实际缺口

ADR-0032仅保存10秒模拟任务，旧媒体路径只接受5秒作业，资产校验最高7秒；旧合成异常会终止任务，不能支持“视频已生成，只重试字幕”。已认可的探店视频本地识别仍出现咕嘟/孤独等同音字，计划口播不能当作实际说出的字幕。沿用任务、账本、outbox、私有对象存储和已有FFmpeg合成，比重新制作一套任务系统小；代价是新增原视频保存与字幕状态，以及本地ASR的部署依赖。

## 实现边界

- 新增 native_marketing_media 保存原视频哈希、私有对象键、时长、7天有效期和字幕状态：transcribing → review → ready。原视频一经保存不可替换，识别原文与用户确认稿分别保存。
- 0029创建字幕表，0030补强ready哈希非空及营销成片时长上限。旧5秒发布仍使用7秒校验，只有已确认字幕的10秒发布可用新上限；未放宽旧逐镜资产约束。迁移只应用于本轮隔离库。
- 原视频先校验10秒附近时长、720P竖屏、音轨和哈希，再私有保存。媒体工作进程采用已在本机准备的 faster-whisper small CPU 模型，禁止运行时联网下载；逐字时序分组生成草稿，拒绝时间重叠/越界，不自动用计划文案替换同音字。
- 用户播放原声、按需改错字、确认字幕后，本地烧录字幕与AI标识，保留原声内容。无新TTS、无新视频生成。确认稿/原视频哈希/版本校验、资产发布、原预留结算和作业完成在同一数据库事务。
- 本人认证后才可读字幕和签名原视频；公共响应剥离对象键等私有字段，签名最长10分钟且不超过文件有效期。
- 确认按请求键和内容幂等；同键异内容或不同确认版本冲突，不能覆盖已确认稿。重试恢复沿用同一作业，无新积分预留。
- Temporal新增10秒分支，先查已保存媒体，再决定是否需要原供应商回执；保存后继续处理不依赖供应商临时URL。字幕识别/合成失败保留原片及预留，允许恢复，不调用旧的失败退款处理。旧5秒历史分支保持原活动序列。真实渠道仍在取得提交权前拒绝10秒任务。
- 小程序按账户/任务保存字幕编辑草稿和未知确认请求；未知503或错误回执不能清理，重试固定原内容和请求键。成片后才出现保存按钮。开发演练明确使用固定样片，不把已有素材称为本轮新生成。
