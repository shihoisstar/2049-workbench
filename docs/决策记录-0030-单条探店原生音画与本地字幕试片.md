# ADR-0030：单条探店原生音画与本地字幕试片

2026-10-11。负责人同意先免费准备1条完整探店样片，冻结方案与预算后单独确认付费；先探店、再剧情带货，两条业务及漫剧整体目标不变。

## 固定方案

虚构火锅店、10秒、9:16、720P、同一成年女主持人；0–3秒人物指锅底开场，3–6秒锅底/牛肉/蔬菜近景，6–10秒回到同一人物收尾。中文连续台词：

1. 哇，你看这锅红油，咕嘟咕嘟的！
2. 牛肉、蔬菜，满满摆了一桌。
3. 来，夹一片牛肉下锅！你想先涮哪个？

使用Atlas `bytedance/seedance-2.0-fast/text-to-video`，显式generate_audio=true、ratio=9:16、bitrate_mode=high。一次请求同时生成画面/说话/轻微环境声；字幕本地后期叠加，不依赖模型直接画字。不给参考录屏中的人物身份、店名、地址或商家事实作为生成输入；本轮无真实商家素材，只验证人物动作/表达/镜头/音画/字幕能力，不能算真实门店还原验收。

## 先修正的已知失败路径

旧通用视频适配器发送aspect_ratio；该模型文档需要ratio，并支持generate_audio。仅为此明确型号补参数分支与范围检查，不泛化修改其他型号。当前线上营销5秒契约、钱包与任务快照不改，10秒仅为隔离试片。

原有字幕不能直接用计划稿代替实际语音。Atlas xAI STT文档的语言枚举未列中文，本轮不花钱试不明确的语种支持。复用成熟faster-whisper 1.2.1（small、CPU int8）和OpenCC 0.1.7，在.local独立Python环境处理生成音频。模型从Systran公开仓库下载，固定revision并保存文件哈希；识别时仅读本地模型/媒体、不作云端调用，也不把计划正文注入识别提示。

字幕保存词时间和识别置信度；繁简转换保留原识别文字。全文与计划不符、词时间重叠/越界、置信度偏低时停止自动烧录，保留差异供核对。符合基本检查后再用共有ASS/FFmpeg合成并保留视频原音轨。识别一致不代表主观真人感或精确口型已验收，最终仍由负责人对照参考观看/试听。

## 成本和恢复

拟申请1次视频请求、本轮人民币上限10元、程序保守预留$1；当前公开模型页$0.027/秒，10秒参考估价$0.27，账户实扣未知。提交前再只读核对公开价，未知或超限不提交；不把估价标成账单。无额外生图、TTS或付费ASR。模型权重下载和CPU转写不产生API调用费用，本地计算仍消耗时间和资源。

脚本`real-native-visit-sample.cjs`：prepare离线，execute必须具备本轮人类授权及明确金额标记；一次提交前持久记录、锁防并发、未知不重发，已有ID仅GET恢复。transcribe/compose均免费本地步骤。此前12次媒体和2次试听额度不复用；本轮尚未获得付费授权。

代价限于一个供应商参数分支、一份受控试片脚本和本地验收辅助工具；没有新业务表、商用字幕服务或口型处理系统。后续若试片达标，再评估部署字幕识别、时长报价与普通用户自动制作。

## 本轮真实结果与待核对字幕

`node scripts/real-native-visit-sample.cjs --execute --authorized-native-cny=10`退出0，实际POST1、重复0；原片720×1280、10080ms、带音轨。原ID只读GET显示completed，回执price $0.5830272，低于$1预留但高于模型页估价$0.27；不能依赖该页基础价作为720P最终结算，后续报价需保守估算/核对计价细节。账户实扣未对账，授权次数已用完。

`--transcribe`退出1，原因是实际识别稿两处与计划不符（“孤独孤独”/“咕嘟咕嘟”，“上”/“涮”）；未删断言或把识别稿覆盖成计划稿。原始识别结果在transcript.json。由于本助手不能直接听辨，依据上下文和计划作两处暂拟修正，以ASR时间制作5条字幕，保存到captions-review-draft.json，humanVerified=false、transcriptMatchesPlan=false。用共有composeDramaExport另做明确命名的store-visit-review-draft.mp4，仅供负责人试听核对，不能当自动字幕正确性证明。

`ffprobe`读取待核对预览：720×1280、10.080秒、H.264/AAC；文件SHA-256为99845653879696d9e2c4fedd380e5eeb8780fd279facbacbd71163c4daf812ef。本地每秒抽1帧、共10帧检查原片，再查看成片2/4.5/9.2秒帧：人物/衣着/背景在抽样中保持相近，已出现人物→食材→人物的切换，字幕在画面内可读；未完成全片运动、声音自然度、嘴型同步与两处文字确认。主持人表情、夹起肉片的形态与动作也须按参考由负责人评审，尚不标商业质量合格。

本轮没有业务代码修改或新测试运行；只执行已授权媒体请求、免费本地识别/合成/读取核对。报告和回执价格已脱敏落盘，私有ID仅在.local。

## 负责人质量确认

2026-10-11，负责人观看后明确反馈“可以可以这个质量可以非常好”。将该单条虚构探店样片的整体画面/声音品质标为人工认可，并冻结原输出哈希作为后续对照。两处字幕歧义没有逐字单独确认，保留原始ASR和暂拟修正记录，不据此降低自动字幕门槛。文件名保留以免既有链接失效。下一步按此前确认顺序准备剧情带货样片，随后接入正式制作；本次认可没有追加任何付费额度。
