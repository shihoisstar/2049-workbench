# ADR-0037：剧情带货现场对白默认要求与录制质量验收

日期：2026-10-12。背景：MK-PILOT-QUALITY-20261012-B2。负责人亲自按正常流程录制的结果为旁白、声音僵硬，不能交付领导；此前助手演示依赖手动补写拍摄要求。两份真实POST的重建哈希均匹配提交日志，模型、原声/高码率参数及商品图一致，现有失败路径并未被默认模板阻止。

## 当前修正范围

沿用已有文案作业、原生视频模型和字幕合成，不增加用户字段或额外生成服务。10秒剧情带货的文案系统提示明确成年女主人公现场对白、两至三句台词及对应的动作/表情，建议25–35汉字且保留40字上限。数字镜头编号/秒数不输出，避免误触现有商家事实数字校验。

原生剧情带货请求明确由画面中的女主人公亲口说话，嘴部可见，一句说完再切商品特写，台词短则保留自然反应与停顿，不擅自添加台词。默认要求不再依赖助手人工追加。探店视频提示正文和旧5秒制作链路保持原行为。

文案绑定随系统提示哈希更新；原生promptRevision由1升至2，旧报价须重新核对。修改既有提示会增加输入文本，但不新增调用次数；维护面为两处提示和原生绑定版本，新增风险是旧未完成任务不能在配置变更后直接改用新提示。本次已确认试用库没有未完成生成/文案任务，既有成片与来源保留。未来仍按原绑定保护核对未完成任务。

## 验证与质量边界

免费验证检查文案作业快照、绑定及实际worker序列化请求包含现场对白要求，重投仍只有一次POST；不能据此声称模型一定遵循指令、音色自然或口型合格。修改后的真实生成尚未执行，不能把“提示已补齐”称为“质量已修复”。

下一轮若获新的明确费用授权，应使用正常用户输入→文案→采用→视频路径，不再额外手工补藏在演示脚本中的提示。先留存完整原始录屏，负责人观看确认人物说话、自然程度、动作与商品外观后，才整理领导汇报；不同任务不得拼接成一次实时生成的假象。当前失败任务及原始录屏保留。

本决策不授权新增付费调用。B1底栏遮挡按负责人要求继续后置。
