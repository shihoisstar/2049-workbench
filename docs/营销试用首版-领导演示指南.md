# 2049出片：营销视频试用版汇报指南

## 这次向领导交付什么

剧情带货、探店两个入口，展示输入/上传素材、文案确认、后台制作、字幕核对、作品找回和文件保存。先用已认可的猫咪帆布袋、火锅店作为演示案例。

这是本地试用版，尚未公开上线。没有微信认证也可以先在微信开发者工具中演示；本次不演示微信支付、手机号授权或正式发布。开发者工具里的“保存视频”保存到小程序本地文件，**不能讲成“手机相册已验收”**。交付包另外导出可直接播放的MP4。

官方依据：[微信测试号说明](https://developers.weixin.qq.com/miniprogram/dev/devtools/sandbox.html)提供开发测试和真机预览能力。用户现有账号能否上传体验版、公开发布仍以其后台权限/办理情况为准，不从模拟器可运行推断这些权限。

## 录屏前提

1. 在这台开发电脑上运行；已安装并登录微信开发者工具。
2. Docker、本地API、任务进程、私有存储、本地字幕识别工具都已启动。
3. 真实新生成需要网络可达Atlas，而且必须先获本轮费用授权；不要连续点“重新生成”。
4. 手机访问不了电脑的127.0.0.1，因此这份本地配置只用于开发者工具。后续真机另配可达地址和网络条件。
5. 用系统录屏或现有录屏工具，录制**模拟器区域**；不要把终端、密钥、数据库连接、调试Storage面板录进去。

## 环境和命令

工作目录：`D:\2049-workbench`。

首次启动或后端代码更新后，先完成构建，再启动试用服务：

```powershell
pnpm --filter @wb/api-next... --filter @wb/worker... --filter @wb/media-worker... build
```

完整检查 `pnpm verify:isolated` 会重新构建共享依赖，应先结束检查再启动试用服务，避免录屏中后台进程退出。

恢复既有真实作品而不发起新增付费调用（ADR-0040）：

```powershell
node scripts/start-marketing-pilot.cjs --live --no-paid-calls
```

该模式沿用3037和原数据库/文件，不修改历史审批或消费记录；新视频与文案受理关闭，原请求重放、作品读取和媒体处理保留。运行中的服务与所请求付费模式不一致时会拒绝启动，须先明确停止原服务。需要独立后台运行时，在项目根目录使用现有Node启动，并把主进程日志直接写入专属目录：

```powershell
$pilotNode = (Get-Command node).Source
Start-Process -FilePath $pilotNode -ArgumentList 'scripts/start-marketing-pilot.cjs','--live','--no-paid-calls' -WorkingDirectory 'D:\2049-workbench' -WindowStyle Hidden -RedirectStandardOutput '.local/marketing-pilot/live/supervisor.log' -RedirectStandardError '.local/marketing-pilot/live/supervisor-error.log'
```

状态文件记录supervisor和两个worker PID；不使用新的费用授权来恢复历史任务。开启新模型调用仍须先确认次数与预算。短时恢复验证见 `docs/验收留档/LOCAL-RECOVERY-2026-10-12/report.json`，不代表全天或生产稳定性。

```powershell
# 免费演练：固定样片，画面必须保留“开发模拟”说明
node scripts/start-marketing-pilot.cjs --rehearsal

# 新终端构建独立试用项目
$env:TARO_APP_API_NEXT_BASE='http://127.0.0.1:3036'
pnpm --filter @wb/miniapp build:pilot:weapp
```

在开发者工具导入 `D:\2049-workbench\apps\miniapp\dist\marketing-pilot`。仅包含创作、作品、我的和制作进度；原studio项目继续保留。

真实验收模式使用3037端口，**须获单独费用授权，准备好批准文件后才启动**：

```powershell
node scripts/start-marketing-pilot.cjs --live
# 构建时把上面的API地址改为http://127.0.0.1:3037
```

后台窗口需要保持运行。停止命令如下，停止会保留数据库和作品，不会删除数据卷：

```powershell
node scripts/start-marketing-pilot.cjs --rehearsal --stop
node scripts/start-marketing-pilot.cjs --live --stop
```

再次启动对应模式可恢复历史作品；到期文件仍遵守页面有效期，请及时另存MP4。真实演示与免费演练使用不同数据库，不能混成一个“真实生成”演示。

## 建议录成3–5分钟

| 时间 | 操作 | 可以这样讲 |
| --- | --- | --- |
| 0:00–0:15 | 展示创作页和两个入口 | “这是2049出片营销视频试用版，目前演示本地微信开发者工具环境。” |
| 0:15–1:00 | 选剧情带货，上传猫咪帆布袋图，填写真实描述，选用或手动修改文案 | “用户给素材和想法，可以直接写，也可以让AI提出文案，再自己确认。” |
| 1:00–1:30 | 确认内容和试用积分，提交一次 | “生成前先说明本次费用；视频可预览后结算一次，后面的字幕核对、合成重试不重复收费。” |
| 等待段 | 展示受理、离开后从作品找回 | “任务在后台继续，退出页面不会丢失。”真实等待可剪短或加速，片上写明“生成等待已加速”。 |
| 1:30–2:30 | 播放原声、核对字幕、改一处错字、确认成片 | “字幕根据实际声音识别，用户可以核对修改。”不要将人工校正说成全自动准确。 |
| 2:30–3:10 | 保存视频、作品列表、再打开播放 | “成片可以找回和保存。这里是开发者工具本地保存，手机相册另外验收。” |
| 3:10–4:00 | 展示探店的另一条真实成片 | “同一套流程也支持探店，内容围绕门店环境和商品。” |
| 4:00–4:30 | 展示交付文件和下一步 | “本轮交付营销试用流程和两条MP4；认证、支付、正式部署及真机发布是下一阶段。” |

第一次真实验收时最好同步录制，避免为了录屏再生成一遍。之后可录制已完成任务的查看、字幕演练和播放，但应明确标为“历史任务回看/演练”，不能伪装成刚刚实时生成。

## 把成片交给领导

后台仍运行时执行：

```powershell
node scripts/export-marketing-pilot.cjs --live
```

输出到 `D:\2049-workbench\artifacts\marketing-pilot\live`：剧情带货.mp4、探店视频.mp4、交付文件说明.json。缺少任一真实成片会提示，不会用演练素材顶替。

汇报包建议包含：演示录屏.mp4、两条成片、这份指南中的“本次完成/下一阶段”摘要。发送领导由你执行，本工具不会自动上传或发送。
