# ADR-0027：免费制作计划与受控真实短样片

2026-10-11。负责人授权先整理制作计划、准备漫剧及带货/探店真实短样片；新增付费调用先确认。

现有失败路径：deriveStoryboardShots将每段原文拆成一镜，分镜没有时长规划；直接批量调用会把短动作和短对白各自付费。视频/营销当前仅5秒，按对白字符数不能保证实际配音适配；实际评测有剧本超长、商家性能补写，无法直接扩大到5条正式成片。

新增免费只读制作计划，按同集/同场景相邻段落合并建议镜头，保持原文、来源镜头、角色引用和画面修改完整；不覆盖既有草稿/选图/视频。合并受内容长度、角色数和估算时长限制；长段落标需调整，不自动删字或裁切对白。中文口播暂以每秒3–4个字及停顿估算，明确estimate_only，真实配音后校准；不是配音时长事实。支持缺集、目标60–120秒偏差、过长镜头及失效引用提示。

营销免费计划仅解析用户确认/编辑的口播和画面，5秒参数沿用当前真实契约，超时提示不默默加速；不生成新商家事实。界面展示集数/镜头/时长与问题，详细安排可展开，报价未知显示待确认。

短样片以独立小额评测准备：一段小猫漫剧含两个镜头、带货与探店各一个镜头，共4个5秒镜头，9:16、720P。复用现有Atlas图像/视频适配器及FFmpeg，补语音协议；固定输入与模型，持久请求前日志、累计次数/保守预算保护、未知停止不重复POST。样片程序和免费注入验证完成之后才请求新付费授权，既往14次文本额度不复用。商业API真实受理继续关闭。

代价：增加只读契约/纯规则/计划卡片和受控评测脚本；本阶段不增加业务表或第二套调度框架。合并是可核对建议，非自动导演质量保证；角色一致性、真实配音对齐和实际成本由样片实测，随后再实现一次确认后台自动制作及完整5集。

负责人后续明确批准本轮最多12次媒体调用（4图/4段5秒720P视频/4段中文旁白），使用现有Atlas与上述固定模型，人民币预算20元、程序保守限额$2，未知即停、不自动重发。允许分阶段、逐帧执行以提前发现问题并少花费用；不追加文本请求。负责人同时确认：小程序认证未准备，微信支付商户号、服务器和域名已有；接入可用性尚未核对。

实测在第9次停止：PNG请求返回JPEG，试片本地规范化；720P视频实际704×1248，保留回执且不重复POST、不放大冒充达标；两镜角色服装和驾驶舱有变化，尚不能认定跨镜一致。首段诊断合成暴露竖屏字幕溢出，已用实际画幅参数修复共享ASS。剩余3次视频未用，先免费核对规格和调整制作输入约束；新模型或新增范围另行确认。详细证据见REAL-SHORT留档。

后续免费核对官方文档确认Seedance 1.0 Pro Fast的720P/9:16原生输出就是704×1248；暂停源于本地检查过严。仅对该固定模型补明确规格，原ID继续GET后完成剩余已授权3视频，累计12次无重发，三条短样片均已合成；保留全部真实尺寸和质量未验项，不声称原生720×1280。证据与来源已记REAL-SHORT。
