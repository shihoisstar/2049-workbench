# ADR-0024：双业务简化交互与多集交付语义

2026-10-11。负责人明确授权：AI漫剧和营销短视频均需交付；交互简单，选择5集须最终完成5集，尽可能降低成本。

## 证据与当前缺口

- 创建项目保存1–40集，当前剧本任务只处理第1集；confirmScript仅查格式，没有查计划集数。一个5集项目可确认仅1集的剧本，后续分镜继承缺失内容，当前失败路径未被封住。
- 营销页分类只改变标签与示例图，提交不携带带货/探店场景；“AI润色”填固定示例。默认香水文案也会进入探店请求。
- 对标截图可证实总集数和双营销入口，付费后的逐步确认、批量制作方式未取得实际证据；不能把本决策当成对标实测结果。

## 交付与交互

1. 漫剧集数为最终独立视频数。5集须有第1–5集的连续内容、共享角色及逐集可恢复任务、音视频合成和保存；剧本/图片完成不能算视频完成。
2. 默认用户确认故事及主要形象、制作范围与明确费用后自动推进。逐镜编辑/选图/重做作为可选入口，不强迫每个镜头手动操作。批量价格和授权范围需落在持久作业中后才可自动收费，不能靠前端循环默示授权。
3. 营销默认为场景选择、资料/素材、文案确认、报价与制作、成片保存。带货与探店分别保留输入并携带场景，未提供的价格/地址/功效等不得补写成事实；文案助手未接真实模型时不称AI润色。
4. 两条业务共同验收。漫剧先短单集质量试片，再完整5集；营销带货/探店各一条实际样片。微信真机作品恢复和保存相册为共同交付标准。

## 本切片实施边界

- 封住剧本确认的集数缺口，显示每集剧本状态。未确认的导入剧本可采用同一剧本的修复版本；确认后固定引用不变。
- 营销分类进入契约、数据库和供应商上下文，同请求键改分类必须冲突；老请求未提供分类时保持原行为。前端分别保存两类描述/素材，提交费用明确确认，上传期间不可生成。
- 不改第1集真实剧本报价承诺、不伪装已完成多集自动生成、不自动发起新增收费调用。本切片不是5集成片验收。

## 代价与后续

复用当前项目/版本/视频作业/账本，不另建任务框架。新增营销分类字段与迁移，增加兼容旧请求及幂等比较的维护面；分类上下文只能约束提示，不能证明真实视频准确性。完整多集需持久生成分集剧本与汇总版本，固定续作上下文、按已确认预算驱动作业、保留分集失败成果；新分镜到视频/音频/导出仍需接通。真实模型费用仍受既有授权次数和预算约束。
