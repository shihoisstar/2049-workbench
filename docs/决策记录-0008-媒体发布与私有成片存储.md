# ADR-0008：媒体发布与私有成片存储

- 日期：2026-10-06。范围：R2.2营销视频纵向切片。
- 状态：本地真实供应商、微信开发者工具播放及本地保存实证；生产部署和手机相册未验收。

## 当前失败路径

ADR-0007只把上游成功推进到ready_for_media；此前没有资产表、媒体worker和可归属的下载端点。直接返回上游URL会绕过归属检查、标识与持久存储，不能据此结算并宣称成片完成。模拟任务已实际复现媒体失败后退款，见VIDEO-2026-10-06/mock-task-proof.json。

## 决策

1. 独立媒体进程apps/media-worker在单独Temporal队列处理下载、校验、ffmpeg标识、上传；packages/media承载媒体与S3实现。模型密钥不进入媒体进程。
2. 供应商URL仅内部使用。HTTPS、公开IP/DNS固定、逐次重定向检查、超时及64MiB上限；ffprobe/ffmpeg仅处理本地文件，不允许外部引用。真实视频含可见“AI生成 · 2049出片”和comment元数据；不据此宣称所有上线合规要求完成。
3. 私有S3对象按job与sha256定位。0004迁移增加media_assets；资产记录、任务成功、积分结算在一个数据库事务中发布。重入返回既有资产，不再次扣费。对象存储与数据库没有跨系统事务：可能留下未引用对象，生产需要孤儿清理；不能声称零泄漏或exactly-once。
4. GET /v2/generation/{id}/media验证本人归属和7天逻辑有效期，返回最长10分钟签名URL，响应no-store。签名链接有效期内持有者可访问，不是逐字节重新鉴权；7天逻辑失效不等于物理对象已删除。
5. 本地验收使用单节点Garage v2.3.0、固定镜像digest、独立PG/Temporal及持久卷。MinIO镜像和下载在本机失败，Garage只替代本地S3验收依赖，不改变生产托管存储目标。凭据仅在忽略的.local目录。旧数据库不迁移、旧部署不切换。
6. 微信开发者工具使用文件系统持久保存，并与成片大小/MD5核对；手机代码调用saveVideoToPhotosAlbum。工具内保存与真机相册必须分开陈述。

## 代价和边界

转码会降低保真度，增加ffmpeg/font与对象存储维护面；独立队列增加进程和故障点，但使媒体CPU/凭据与模型执行隔离。当前只验证5秒480P文生视频；参考素材上传、长视频、漫剧合成、生产存储生命周期、内容审核、微信HTTPS域名及真机仍待完成。默认生产API继续关闭生成，仅显式本地验收装配启用。

## 实证

- 真实任务5903130a-88f4-4724-bbc1-66a4a15c0d2f：480×836、5088ms、469596字节；积分预留77/结算一次，余额3。
- 微信播放器实际事件“播放结束 · 5.1 秒”；保存后getFileInfo读取的MD5与后端对象一致。
- storage-proof.json：匿名拒绝、签名GET、Range、过期拒绝及哈希核验；该文件明确为合成测试素材，不冒充真实生成。
- 其他账户成片端点404、未登录401；资产发布回滚与并发测试保留正确不变量。
