## 2. 已确认的创作主链路

首页流水线可视化(S02 顶部)+ 已探明的表单,链路为:

```
① 创建项目(名称/想法或剧本/风格/尺寸/集数)
② 生成剧本          ← 想法模式才有;剧本模式跳过,且"AI严格按照你的剧本"
③ 提取角色/场景      ← 独立一级阶段:角色一致性是产品的核心资产
④ 生成分镜图片
⑤ 生成视频           ← (S02 右侧被截断,后面还有步骤,待补)
⑥ …待探明(推测:合成/配音/导出/发布)
```

要点:**①-⑤ 是官方自己展示给用户看的进度结构**(不是我们猜的),我们做自己的工作台时可以以此为基线再改进。

## 4. 剧本格式规范(从 S03 背景样例提取,生成端和我们的解析端都要兼容)

```markdown
## 第一集：重生昔白日
**场景一：高三教室 日/内**
（铃声响起，学生纷纷落座。沈微坐在第三排靠窗位置，……她猛地抬头，
看向黑板上的高考倒计时牌——"距离高考还有87天"）
沈微（OS）：87天……我竟然真的回来了。30岁的沈微，回到了18岁这年。
（她缓缓转头，目光落在教室后排角落——程飒正趴着睡觉，……）
```

结构规则:
- 层级:**集(`## 第X集：标题`) → 场景(`**场景N：地点 时间/内外**`) → 指示(括号行) → 台词(`角色名：`)与 OS(`角色名（OS）：`)**
- 时间/内外标记:日/夜 × 内/外(影视剧本惯例)
- 这就是"提取角色/场景"步骤的解析对象 → 我们后端做剧本解析器时按此设计,角色表/场景表从这里抽取

## 8. 第二批实测结论(S08-S13,2026-10-02)

### 8.1 账号体系(S08/S09)
- **游客模式可用**(用户名"游客"),账号管理仅两项:验证手机号 / 切换到其他账号 → 低门槛进入,推测支付/保存时才要求手机号(待验证)
- 作品按 视频/绘画/工具/收藏 四类管理;作品空态用"纸箱"插画 + "暂无作品记录~"

### 8.2 会员权益 = 模型能力的分级墙(S08)
- 超级会员卡:"解锁无限制使用所有功能",权益标签:**Seedance模型** / 漫剧极速生成 / 定制专属漫剧 / 一键成片 / AI改图
- **重大发现:Seedance = 字节跳动的视频生成模型** → 这个 APP 的本质是字节模型的"积分转售商",成本被上游价格(即梦涨价)直接卡脖子
- **对我们的启示:模型层必须设计成可切换/可聚合,不能绑定单一上游**

### 8.3 存储策略(S08)
- **"视频内容云端保存 7 天,请及时下载保存"** → 成本驱动的保留策略;我们的产品同样要设计生成物的存储 TTL + 下载引导

### 8.4 剧本库是独立实体(S10)
- 我的剧本:独立列表 + "添加剧本"入口 → 剧本(ideas/scripts)是可复用资产,与作品分开管理

### 8.5 创作 tab = 多场景模板市场(S11)
- 顶部 banner:**AI门店视频**("一句话生成爆款种草视频") + 剧情带货 / 探店视频 双入口 → 产品范围远不止漫剧:短剧/漫剧+带货+探店+绘画+一键成片,是多场景 AI 视频套件
- 分类 tab:剧情带货 / AI绘画 / AI短剧 / 一键成片 / 文[生视频?]
- 模板卡片带**"生成同款 N万"使用量**(4.5w/10w/72.7w)→ 社会证明 + 模板热度排序的原始数据
- **定位启示:它横向铺多场景,每个场景都浅;我们纵向做深漫剧工作台,是错位竞争**

### 8.6 创作同款 = 模板预填机制(S12/S13)
- 点"创作同款"→ 直接进创建表单,预填:标题(案例名)、120 字专业级故事想法、类型自动选中(穿越)
- **表单校验逻辑确认:必填字段为空 → "开始创作"灰色不可点;预填后点亮**——之前"灰按钮"不是积分拦截
- 模板数据结构推测:`{title, idea_premise, genre_type, video_style?}`(待进一步验证是否含风格/尺寸)
- **印证:模板 = 内容团队的题材知识配置化**,这是它真正的护城河所在

## 13. 第三批实测结论(S16-S26,2026-10-02 22:09-22:11)

### 13.1 带货/探店流程 = 原始模型参数面板(S17-S20)——本批最重磅
- 剧情带货/探店视频两个 flow 的表单完全同构:热门案例(点素材看创意描述示例)→ 上传图片(选填,JPG/JPEG/PNG ≤10M)→ 灵感描述(≤3000字,"短句短语为佳",带 AI生成文案 / 随机 / 清空)→ **选择模型** → **参数配置** → 确定生成
- **模型选择外露:Seedance 2.0 基础版("新一代高性价比模型")/ Seedance 2.0 专业版("新一代专业模型")**
- **参数配置外露:视频时长 5s(默认)/ 视频尺寸 16:9(默认)/ 分辨率 480P(默认)**
- 解读:①这两个场景是字节 Seedance API 的薄封装;②基础版默认 480P = 成本控制的明牌;③漫剧 pipeline 才是高抽象封装(不暴露模型/参数);④**同一 APP 内并存两种抽象层级——场景化深封装(漫剧) vs 参数化薄封装(带货/探店),我们的工作台可以两者都要**

### 13.2 会员权益完整表 = 双轨制货币(S21)
- 8 项权益:漫剧创作 / Seedance模型 / 创作同款 / 一键成片 / **优先制作** / 多种风格 / **无水印导出** / **赠送1200积分**
- 模式确认:**订阅(解锁能力+QoS) + 积分(按量付费)双轨**;会员送 1200 积分(≈周卡¥38 买 1200 积分 + 能力解锁)
