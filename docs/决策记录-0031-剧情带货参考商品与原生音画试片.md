# ADR-0031：剧情带货参考商品与原生音画试片

2026-10-11。负责人已认可单条探店样片质量，并要求继续。按此前确认顺序先准备剧情带货样片，再将两类已验证能力接入小程序；新增付费仍单独授权。

## 本轮方案

复用已生成的虚构橘猫帆布袋图片，不新增生图请求。源为REAL-SHORT试片的commerce-frame.png，拷贝到NATIVE-COMMERCE/product-reference.png并核对SHA-256：f94e6f4ad5d471b482f33634180a092a95c16ec245e3f598adef71623280a404。768×1376、PNG、1409876字节。它是虚构样品，不能当真实商家商品保真验收。

10秒、9:16、720P、原生同步女声：成年女性准备出门、手拿手机钥匙略显忙乱→发现木椅上的小猫包并提起→装好物品、提包出门。三句台词为“哎，出门又拿一堆东西！”“原来你在这儿！”“装好！带上小猫，一起出门。”无价格、优惠、性能或体验背书。检查商品袋身、提带和橘猫图案在动作和不同景别中是否保持一致。

使用Atlas `bytedance/seedance-2.0-fast/reference-to-video`，通过reference_images发送唯一已核对商品图的data URL，固定ratio=9:16、generate_audio=true、bitrate_mode=high。仅参考商品外观，人物由模型新生成；不输入用户提供的参照App人物身份或原声。

## 最小实现与代价

已证实旧适配器会将有图请求发送为image_url/image_urls，不能表达该型号文档要求的reference_images。补该明确型号图片参考分支，校验1–9张有值的图片引用并保留顺序；与已有T2V共用原生音画参数。无新增参考音频/视频处理，也不新增商品资产服务或调度框架。

复用已有受控试片执行器，增加明确的--commerce分支与独立目录、计划指纹、回执、费用标记。旧探店计划指纹和已认可文件保持不变。新商品图每次提交前重新核对哈希，旧探店授权标记不能用于带货；一次POST、unknown停、原ID只GET恢复。

字幕继续使用本地faster-whisper词时间与共有ASS合成。与计划不符或时间不可靠时停止自动烧录，不用计划稿掩盖实际语音；如需修订只保留单独标识的待核对字幕版本。产品图不变形、动作可信、声音自然及字幕正确都须在真实结果中验收，单条成功也不代表任意商家商品都稳定。

## 拟申请费用

最多1次10秒参考视频生成，本轮人民币上限10元、程序保守预留$1。公开模型页仍列基础价$0.027/秒，但已认可的探店同规格实际回执为$0.5830272，高于按页面简单相乘的$0.27；本轮不把基础价当结算承诺。提交前再次只读核价，未知或基础估价超限停止；实际账户扣款另核对。参考输入可能影响最终计价，保留保守预留。

前面的媒体12次、语音2次、探店1次授权均已用完，本轮尚未获得付费授权。首版生产5秒契约、支付和小程序入口未随试片直接开放。

请求与素材：`验收留档/NATIVE-COMMERCE-2026-10-11/request-plan.json`、`product-reference.png`。执行入口：`node scripts/real-native-visit-sample.cjs --commerce --prepare`；实际execute需本轮负责人授权及`--authorized-commerce-cny=10`。

来源：[Atlas参考视频接口及价格](https://www.atlascloud.ai/models/bytedance/seedance-2.0-fast/reference-to-video)。本轮只读取公开资料、复用原素材与离线验证，没有新模型调用。

免费准备验证：`pnpm verify:isolated`退出0，53任务/360测试/失败skip缓存0，363模块/1287依赖0违规，14HTTP；运行号wb-verify-0f7af907-9f27-46cd-8dca-1ffadee87615。离线次数/参数/参考图/字幕/旧指纹检查12项、失败0、网络0；误用旧探店授权标记的执行探针退出1、调用0。已认可探店视频哈希未变。真实参考视频受理、商品一致性与听感仍未验证，未提交或部署。

负责人后续明确批准本轮现有Atlas、Seedance 2.0 Fast参考视频最多1次，10秒720P同步女声，参考图复用，本轮人民币10元/程序$1保守限额；未知即停不重发。此批准不包含重做或追加生图。

## 真实执行结果

`node scripts/real-native-visit-sample.cjs --commerce --execute --authorized-commerce-cny=10`退出0：POST1、重复0，原ID查询completed；原片720×1280、10080ms、有音轨。回执price $0.5830272，低于$1预留，账户实扣未对账，本轮授权已用完。参考商品PNG哈希固定，没有追加生图。

`--commerce --transcribe`退出1：识别正文仅缺计划开头的“哎”，其余规范化文字一致。没有删除或放宽自动断言；保留原识别数据，另用4条来自实际识别文本与词时间的字幕制作commerce-review-draft.mp4，未补入未识别语气词。captions-review-draft.json记录transcriptMatchesPlan=false、captionTextMatchesRecognizedSpeech=true、humanVerified=false。不能由语气词缺失判定模型实际漏读，须人工听辨。

`ffprobe`核对预览：720×1280、10.080秒、H.264/AAC；SHA-256 5ac5697c26a9746f7a5685591d211fa517dfee399e03263739529c2125c72bd8。每秒抽1帧共10帧，另看合成1/5.5/8.5秒帧，奶白袋身与橘猫印花可辨、人物有准备/发现/装包/出门动作，字幕在画面内。未完成精确商品保真、全片运动、口型、字幕及自然声音的人工验收；不预先标商业质量通过。

本轮未改业务代码或新增运行测试，仅执行授权试片及本地识别、合成、读取核对；公开文件不含私有回执ID或上游URL。

## 负责人质量确认

2026-10-11，负责人观看后反馈“可以的这个质量还可以”，确认本条剧情带货样片整体质量可接受。原文件和哈希保持不变，作为带货对照；这不扩展为任意商品精确保真、自动字幕无误或商用发布完成。开头语气词没有单独逐字确认，保留识别差异记录。探店与带货两条样片均已有负责人认可，下一阶段按此前顺序推进小程序真实制作闭环，费用确认、恢复、字幕和手机相册仍需接通。此认可不追加任何付费额度。
