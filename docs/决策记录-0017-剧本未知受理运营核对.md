# ADR-0017 剧本未知受理运营核对

- 日期：2026-10-10；状态：实现与隔离验收中。
- 依据：负责人授权继续补结果核对，复用ADR-0015/0016的提交保护及账本。

现有剧本unknown可防止重复付费，但没有运营登记证据的入口。原视频ops没有同样的审计/重放边界，不能直接照搬。

新增`/v2/ops/review/drama-scripts`分页队列与`POST /:id`处置。沿用API_OPS_TOKEN，默认未配置时503；普通用户会话不能代替运营凭证。只列真实、accepted的unknown，或提交超过2分钟仍submitting的任务；不暴露提交令牌、密钥或整段请求正文。

处置必须提供requestKey、原因、证据引用。receipt附完整规范化回执，校验实际任务的模型和供应商；reject必须显式confirmedNotAccepted=true。超时或unknown本身不是退款依据，这个字段表示运营人员核对确认，不是供应商自动证明。

同job仅一份成功处置记录，requestKey全局唯一，保存规范化请求哈希、原因、证据、原状态、操作时间和认证来源ops-token。共享凭证不能证明具体姓名。应用只追加记录，当前没有数据库级禁止UPDATE/DELETE触发器，不声称审计具备数据库不可变保护。

回执与处置记录在job锁事务中一起保存，随后由现有worker独立发布；不在持有job后反向申请project锁。拒绝、退款和处置记录同事务。相同key/正文可重放，不同正文或另一个决定409。回执与拒绝竞争只允许一个结果；已经退款的任务不被迟到正文复活或再次收费。

不新增队列或管理后台空壳，worker现有5分钟后台检查即可接续；未改变工作流控制流。已知回执即使后续发布失败仍保留，未知不可重新POST。0018迁移增加9列的剧本处置表。付费调用额度不变，本轮不调用真实供应商。
