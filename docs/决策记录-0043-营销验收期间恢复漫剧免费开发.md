# ADR-0043：营销验收期间恢复漫剧免费开发

- 日期：2026-10-13
- 状态：负责人已授权恢复免费开发；本轮制作恢复入口完成免费本地验收，真机与真实生成另验。
- 授权：负责人要求按营销验收次序推进能直接完成的工作，并尽快开始AI漫剧功能开发。
- 调整：ADR-0036中“漫剧暂停扩展”的排期约束。营销作为首版的质量、真机和收费验收条件保留。

## 范围和顺序

营销进入真人独立操作、账号条件核对、真实质量、云端真机和受控试用的验收阶段。等待本人扫码、账号信息或费用确认期间，可以继续漫剧的本地可逆开发，不必等待营销公开上线。

漫剧先以一集贯穿现有流程：想法或导入剧本→确认版本→角色/场景→分镜→画面/逐镜视频→台词音轨/字幕/合成→找回与保存。现有多集功能保留，但先完成单集验收后再扩真实多集验证。不新建另一套任务、账本或素材系统。

本轮切片修正“已有分镜的项目重进仍回到角色准备”的实际路径。确认剧本后点击继续制作，从现有latestStoryboardPlan接口读取进度；仅在plan.current且scriptVersionId等于项目confirmedVersionId时进入该分镜，否则进入角色准备。读取失败留在项目页重试，不把失败解释为没有分镜。并发重复点击沿用当前submitting锁。

## 验收条件

1. 有有效分镜，退出重进项目后可恢复同一planId。
2. 没有分镜或准备版本已变化，进入角色准备，不进入旧分镜。
3. 读取失败时原页有准确提示，再点继续能恢复。
4. 导航不创建生成作业或预留/结算，余额保持。
5. 双端构建及完整隔离门禁完成；浏览器、开发者工具和真机结果分别记录。

## 保留的边界

本授权不增加模型费用、调用次数、公开发布、Git提交或旧库迁移权限。真实入口继续关闭新增付费。真实剧本/角色/视频/TTS须在冻结参数、费用上限与未知受理规则后，单独获得费用授权。mock用于功能和恢复验证，不作为真实质量或手机验收结论。

后续切片先核对现有分镜制作计划的缺口，再补实际缺失的画面/视频与音轨闭环；不凭历史任务表把mock实现计为真实交付。
