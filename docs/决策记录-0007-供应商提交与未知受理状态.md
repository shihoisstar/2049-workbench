# ADR-0007：供应商提交与未知受理状态

- 日期：2026-10-06；落实ADR-0005的未知受理处置，关联R2.2/INF-03/INF-04。
- 状态：提交/查询activity与数据库边界、Temporal组合根及outbox分发已实现并做本地恢复验证；媒体资产、人工核对工具和真实供应商验收仍待接通。

## 失败路径与选择

现有网关普通dispatch在submit遇5xx时换渠道重试。注入适配器探针令第一次请求返回502、第二渠道成功，实测providerSubmitCalls=2、networkCalls=0。该行为不能证明第一次未受理；仅靠工作流重试或稳定workflowId不能防止上游重复收费。

采用：先在PostgreSQL持久创建唯一job提交记录，再对固定channel做一次POST。每个job只有第一次claim返回提交token；后续调用只返回记录，不因租约、超时或进程重启重新获权提交。现有网关的其他调用保留原行为，新activity必须传channelId绕过普通failover。

代价：发送前崩溃也可能留下submitting，需要核对，不能自动重发；牺牲不确定情况下的自动恢复速度来避免重复费用。这不是跨数据库/供应商的exactly-once保证。

## 状态与资金

| 提交状态 | 含义 | 重放处理 |
| --- | --- | --- |
| submitting | 已取得唯一提交权，可能尚未发送或已发送但无持久回执 | 不发POST，待核对 |
| submitted | 已保存供应商任务ID | 使用原ID和原渠道查询 |
| unknown | 连接错误、超时、5xx、缺少有效回执，无法确认受理结果 | 保留预留，不自动退款或重发 |
| rejected | 明确的本地前置拒绝或HTTP拒绝 | 同事务记录拒绝、任务失败、退还预留 |

明确拒绝分类：网关未找到渠道/适配器/凭据、明确本地限流/非法请求；HTTP 400/401/403/404/422/429按当前适配器拒绝语义处理。408、409、5xx和传输异常不归为明确拒绝。供应商协议有不同语义时必须调整该渠道适配，不根据异常文案猜测。

只有原token可登记回执或拒绝。相同回执幂等，不同任务ID冲突；unknown可由原调用的迟到回执恢复submitted，已submitted不会被迟到unknown覆盖。拒绝与回执竞争只有一个状态成立。

providerKey包含供应商、channelId以及地址/模型配置哈希，防止配置变化后把旧任务静默交给新渠道。配置应不可变，旧任务保留对应配置；它不是新的凭据存储，密钥与供应商异常正文均不写入提交表。

## 查询与成片

查询重试只执行poll，复用已持久化ID。上游明确failed后通过generation.fail原子退款；queued/processing继续等待。上游succeeded只返回内部ready_for_media结果，不发布临时URL、不结算。

媒体阶段仍须下载地址/DNS/重定向限制、大小与媒体校验、AI标识、对象存储、资产归属确认，最后才能调用generation.complete。当前HTTPS语法检查不等于素材已安全；地址不对客户端公开。

## 验证边界

- 新增server六项真实DB测试：50路唯一claim、重新建立服务连接后不重claim、凭据/归属与冲突、unknown与迟到回执、拒绝/退款故障回滚、回执拒绝竞争、终态禁止新提交（部分场景合并在同一测试）。
- 新增worker六项测试使用真实网关与注入适配器：50路调用仅一次POST、响应丢失与502不切换、无回执、明确拒绝退款、查询重试不POST、上游失败退款与成功等待媒体。
- 测试没有使用真实收费模型；重启检查是重建服务连接/执行器，不是业务worker进程SIGKILL恢复测试。Temporal早期spike的证据不能冒充这条业务链路已验收。
- outbox测试的全局消费语义要求独占数据库；本轮为该套件创建随机命名临时库并清理。其他套件保留随机用户隔离，原断言未放宽。

### 常驻业务worker后续验证

`pnpm verify:worker`在真实Temporal服务、真实PostgreSQL和实际worker子进程上执行：启动后丢失outbox确认→重投仍同run；强制停止worker后signal留在服务端，重启继续同run；mock提交共1次；关闭workflow后同ID不重启，其他类型占用ID会拒绝；39事件历史replay接受。测试最终通过后端失败用例归还预留，不伪造成片完成。真实收费模型调用0次，本次容器清理后0个。

此证据覆盖业务worker重启时等待媒体的恢复，不覆盖提交HTTP与写回执之间强杀后的人工核对，也不代表Temporal服务灾备/生产HA完成。未知受理仍按上文保守处理。证据见docs/验收留档/WORKER-2026-10-06。
