# ADR-0019 角色参考图选择与形象确认

- 日期：2026-10-10；状态：代码及隔离服务端/HTTP验收完成，新增原生选图和真机待验；子项待负责人验收。
- 授权：负责人要求继续角色形象阶段，并沿既定流程推进。

## 现有路径与本轮切片

当前图像任务必须引用分镜候选，候选必须引用角色版本，而角色版本必须已有参考素材。三层NOT NULL外键及受理检查证明首张角色图无法直接套用旧candidate入口。直接放占位图片会破坏ADR-0010的角色一致性边界。

本轮先完成可复用的选择与确认：准备草稿选择真实上传素材→本人短时预览→明确采用→生成或复用不可变角色版本。上传是可选来源；后续自动生成的候选图也进入同一个确认入口，不能自动替用户确认。没有把上传规定为最终产品的必需条件。

## 决策

1. 每个准备角色增加referenceMaterialId，旧草稿默认null；仅配音不允许绑定本次图片。图片仍经已有materials上传、私有存储和7天TTL，不伪造素材ID。
2. 新增本人素材access接口，链接最多10分钟且不超过剩余素材寿命；跨用户404、过期410，不公开objectKey。
3. 采用形象时，客户端只提交角色key、固定剧本版本和准备revision。服务端读取已保存名字、描述及素材，锁user→project→material，检查归属/有效期，固定SHA-256与角色版本。缺少文字描述时使用“以选定参考图为准”，不编造外貌。
4. 新增project+roleKey的选择记录，指向固定roleVersionId，并保存输入指纹。相同输入重放沿用原确认版本，不能被旧技术入口产生的latest版本替换；换图或改描述才创建/采用新版本。旧镜头继续引用原角色版本。
5. 保存草稿不自动确认。选择图后“采用此形象”先保存草稿再确认；保存成功但确认失败仍保留云端草稿。所有这些操作不消耗积分。
6. 过期素材可留在草稿/历史记录中，但不可确认或作为新的模型输入。重新上传同字节是用户明确操作，可按现有上传规则恢复素材期限；确认本身不延长TTL。
7. 附加角色改名后，原角色资产保留。后续自动制作必须从当前准备角色中筛选visual且selection.status=confirmed，引用固定版本；不能从旧工作台全部roles/latestVersion批量取角色。

## 首张AI生成的后续接法与代价

暂不另造portrait的任务/提交/outbox/资产系统。后续给既有image jobs增加明确portrait目标与输入快照，并以互斥约束保持旧candidate语义。首张text-to-image不能套用110积分的reference-to-image定价；付费POST仍须持久提交权、单次submit与可重试poll，不能直接使用自动换渠道重试的generateImage组合方法。

生成图转为参考素材时必须真实复制字节到materials规范路径、固定hash并遵守TTL，不能把assetId当materialId或只登记不存在的对象。当前工作未开启首张AI生成、未追加真实模型调用，模型/价格/质量仍需后续小额评测。

本轮代价为一个六列选择表、准备/素材契约扩展和移动确认控件；不改变既有图片任务或工作流。0019迁移只用于隔离验证，业务库切换另行执行。
