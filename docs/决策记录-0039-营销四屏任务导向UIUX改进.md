# ADR-0039：营销四屏任务导向 UI/UX 改进

2026-10-12。负责人授权按既定开发时序继续，并要求像专业 UI/UX 设计评审一样深入分析全部体验问题，同时改进 UI。依据与19项问题见 `docs/specs/UX-03-营销首版四屏UIUX评审.md`。

保持已认可暖白/炭黑/荧光黄绿、现有营销范围、Taro双端和业务接口。源码与实际截图已证明字体继承缺口、首屏信息失衡、accepted任务阶段混同、字幕主操作/保存反馈位置不清、零结算和UTC时间语义问题。决定在现有结构中重组四屏的信息层级和真实状态表达，不另建产品工程或空功能。

首轮改动：创作/确认步骤与标题、紧凑首屏及费用操作区；AI原稿折叠与编辑稳定；按真实任务/字幕回执派生阶段；字幕固定操作与本机修改保存反馈；任务连接失败自动重读、隐藏暂停；作品的内容简题/分类/状态/继续动作与活动任务更新；积分结算差额/本地时间；成片真实到期日与按钮附近保存反馈。根ui-v2统一字体/可读性和触控尺寸。新展示纯规则加入现有小程序测试入口。

代价：活动作品读取列表后，对已生成但未终结的原生视频额外读取既有字幕GET；只在存在accepted任务且页面可见时10秒更新。状态来自持久回执，不创造第二个业务权威。未知/旧任务保守显示处理中，不虚构百分比或完成状态。接口、迁移和收费模型未变。

权限、长期生产稳定性、正式微信身份、真实封面/搜索、原生tabBar、真机键盘和直接H5下载是独立后续切片。本轮不新增生图/视频/文案付费，不作Git提交、公开发布或生产数据切换。所有验证结果与未验范围如实记录。
