> 用途:搭档技术确认会的三个议题,每个都带数据与来源。取证方式:npm registry / GitHub API / 官网原文 / 搜索三角验证。执行前以控制台实时价复核。

## 议题一:Taro 确认 —— 推荐:确认,证据充分

**流行度数据(2026-10-03 取证)**:

| 指标 | Taro | uni-app |
| --- | --- | --- |
| GitHub stars | 37,707 | 41,615 |
| 最近提交 | 2026-09-30 | 2026-10-02 |
| npm 周下载(核心包) | 36,210(@tarojs/taro) | 35,604(@dcloudio/uni-app) |

→ 两者流行度**打平**,都是一线维护。**所以流行度不是决策变量,决策变量是团队适配**:
1. **语言统一**:Taro+React 使全项目单一 TS(NestJS 后端 / Zod 契约 / React 前端);uni-app 是 Vue 体系,两套心智;
2. **AI 语料**:你们主打后端、前端靠 AI 协同——React 的模型训练语料显著多于 Vue,直接决定 Agent 产出质量与返工率(ADR-0003 核心逻辑);
3. **组件库兼容(见议题二,这是硬事实)**;
4. 京东维护+电商基因,匹配带货/探店场景。

**结论:确认 Taro。uni-app 唯一翻盘条件:搭档是 Vue 老手——他不是(两位都主打后端)。**

## 议题二:NutUI vs TDesign —— 推荐:NutUI,这是兼容性事实不是口味题

**取证结果**:

| 包 | 性质 | 数据 |
| --- | --- | --- |
| **@nutui/nutui-react-taro** | NutUI 官方 **React-for-Taro** 包 | 周下载 8,168;latest 3.0.23 发布于 **2026-09-03**(活跃) |
| tdesign-miniprogram | TDesign 小程序方案,但是**原生 WXML 组件**,与 Taro React 项目不兼容 | 周下载 13,081 |
| tdesign-react | 仅 Web(H5),无 Taro 版 | 周下载 223,496 |
| tdesign-taro | **占位空包**:2023-03 注册,无版本/无维护者/无仓库/周下载 0 | 0 |

→ **TDesign 没有官方 Taro 方案;NutUI 是唯一有官方 Taro-React 支持的主流组件库。** 在已定 Taro+React 的前提下,这不是二选一,是唯一解。权威背书:NutUI=京东出品(电商风,匹配带货/探店),TDesign=腾讯出品——若未来做纯 H5 的运营页可单独引 tdesign-react,不冲突。

**结论:NutUI-React-Taro,议题关闭。**

## 议题三:火山实价复核 —— 推荐:主通道确定火山,模型选型直接抄对标的"基础版/专业版"

**三角验证到的价格(搜索快照,均指向火山官方口径)**:

| 版本 | 价格 | 用途定位 |

| **Seedance 2.0-fast** | **480p ¥0.08/秒**;4K ¥0.32/秒 | 对标"基础版"=高性价比档 → **我们的主力档**(5s 480P ≈ **¥0.4/条**) |

## ⚠️ 附带修正:Atlas 的角色再缩水(ADR-0002 v1.3)

Atlas 官网博客自述:**"Seedance 2.0 尚未开放 API,目前 API 提供 Seedance v1.5 Pro"**(v1.5 Pro $0.247/秒 ≈¥1.75,比火山 2.0 还贵;Fast $0.022/秒是 v1.5 家族)。

→ 这不是偏好问题,是**可得性问题**:
- 对标用的 Seedance **2.0**(S18 实测)目前**只能从火山方舟拿到**;
- "开发期用 Atlas"的原计划**无法覆盖 2.0 模型**;
- Atlas 保留价值:团队熟悉 + 现成适配器(2049 已有)+ v1.5 家族便宜档(开发调试用)。

**修订建议(ADR-0002 v1.3,待你确认)**:**V0 起火山为唯一主通道**(2.0-fast 主力 + 2.0 高档),Atlas 适配器移植为备用渠道(跑通切换演练即可,不进生产主路径)。比 v1.2 更简单:一个供应商一个合规链,发版最稳。
