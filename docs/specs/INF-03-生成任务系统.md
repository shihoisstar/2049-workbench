# INF-03 生成任务系统 — 规格(骨架)

> 状态:骨架(2026-10-03,随 T2.2 工单充实)。真值链:需求池 INF-03 → 本规格 → 实现;状态机行为以 `docs/diagrams/diagrams-v1-20261003/v1-lifecycle.html` 为图形权威。

## 1. 需求与验收(引自需求池)

- 状态机(镜序 §12);幂等键;重试退避 + 上限;内容拒绝/余额不足**不盲目重试**;失败即时退积分(D2);卡单可取消 + 超时自动退(D4)。
- 验收:失败任务积分回账 ≤1 分钟;卡单可取消;重复扣费可检测。

## 2. 技术选型(工单板 / ADR)

- 队列:BullMQ(redis 已由 `infra/docker-compose.yml` 提供)。
- 状态机:镜序状态机;**每条边必须有测试**(T2.2 验收),以 v1-lifecycle.html 逐边对照。
- 退款路径:任务终态失败 → 触发 INF-02 退款流水(billingKey 复用幂等),两规格在此交接。

## 3. 状态集草案(主状态;穷举以 v1-lifecycle.html 为准)

`待提交 → 排队中 → 生成中 → 完成 / 失败(可退) / 已取消(可退)`;
错误分类:内容拒绝(不重试)/ 模型错误(退避重试带上限)/ 余额不足(不重试)。
