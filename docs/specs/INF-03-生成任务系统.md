# INF-03 生成任务系统 — 规格(骨架)

> 状态:骨架(2026-10-03,随 T2.2 工单充实)。真值链:需求池 INF-03 → 本规格 → 实现;状态机行为以 `docs/diagrams/diagrams-v1-20261003/v1-lifecycle.html` 为图形权威。

## 1. 需求与验收(引自需求池)

- 状态机(镜序 §12);幂等键;重试退避 + 上限;内容拒绝/余额不足**不盲目重试**;失败即时退积分(D2);卡单可取消 + 超时自动退(D4)。
- 验收:失败任务积分回账 ≤1 分钟;卡单可取消;重复扣费可检测。

## 2. 技术选型(工单板 / ADR)

- 队列:BullMQ(redis 已由 `infra/docker-compose.yml` 提供)。
- 状态机:镜序状态机;**每条边必须有测试**(T2.2 验收),以 v1-lifecycle.html 逐边对照。
- 退款路径:任务终态失败 → 触发 INF-02 退款流水(billingKey 复用幂等),两规格在此交接。

## 3. 状态集与落地语义(2026-10-04 T2.2 实现,转移表=@wb/domain task-machine,逐边测试锁定)

- 状态:`created → queued → running → succeeded / failed / canceled`;`running --retry--> queued`(受上限约束)。
- 失败分类:内容拒绝(5001/5002)与余额不足(3001)**不重试**;模型错误重试上限 3 次(退避由队列 delay)。
- **受理/轮询两层语义**:attempts 计受理(submit)次数;poll 返回上游终态失败 = 即时退款不再受理;poll 网络/瞬断原地退避续轮询,卡单由 sweep 兜底。
- **发现(熔断×重试交互)**:网关渠道失败后有 30s 冷却,任务级快速重试会全部落空直到熔断过期——单通道时重试≈无效;生产双通道(火山+Atlas)由 failover 兜底。若未来需要"快速重试同通道",须给 router 加绕过冷却的显式开关(记为 V1 候选,不现在做)。
- 超时:queued/running 超 10 分钟(`TASK_STUCK_TIMEOUT_MS`)由 sweep 周期任务自动取消并全额退(D4)。
