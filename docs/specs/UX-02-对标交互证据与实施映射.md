## 已能还原的主路径

1. 漫剧：首页→创作方式选择→想法或已有剧本表单→配置→开始创作。02顶部示意还有剧本、角色/场景、分镜图片、视频，但29张图**没有这些生成阶段的完整实际操作页**；不能声称已从截图掌握角色编辑、逐镜重试和导出交互。
2. 同款：首页案例→已填名称/想法/类型的创建表单→用户修改→开始。预填状态有12/13支撑，具体点击顺序仍属推定。
3. 营销：创作页→带货或探店→参考案例/可选素材/描述→模型参数→确定生成。17–20确认表单结构，任务进度/失败/下载未展示。
4. 账户：我的→设置→账号或水印等；未绑定/已绑定是两种状态。水印可见二次确认；绑定、注销、支付的成功与失败未展示。

## 当前实现差距与本轮落点

- 已修正：AI漫剧新建入口不再直达已有示例分镜；先弹出想法/剧本选项，再进入独立创建页。已有项目卡仍进入示例分镜，保持新建与继续的语义区别。
- 新增：双模式输入、名称30字、想法1000/剧本20000字；想法专用15类型/6风格；共有视频风格、比例、1–40集。本机每模式保存一份草稿，可恢复，清空当前输入需确认。当前不创建后端项目、不扣费；保存会替换该模式此前本机草稿。
- 未完成：案例预览/同款完整预填、真正素材上传、独立剧本库、作品/个人中心、后台剧本生成与解析、角色/分镜/成片真实工作流。本机草稿不是云端项目或剧本库。
- 自有交互选择：小程序View/Button底部弹层，提供关闭按钮与遮罩取消；剧本模式与想法模式切换保留各自当前输入；默认9:16适合竖屏，但并非宣称对标默认9:16（截图默认4:3）。

创建模式正确、切换不丢两份输入、剧本模式不显示故事类型/剧本风格、1–40集校验、草稿保存/恢复、返回首页仍可重新进入；模拟器截图与测试结果另记UI验收。对标弹层动画、手势取消、复杂工作流以及支付/登录失败行为仍需录屏或实机证据，不能凭静态图补成“对标事实”。
