# ADR-0002:分发渠道、支付、技术形态与模型供应商策略

- 状态:已接受(2026-10-02,产品负责人拍板,6 决策点评审)
- 关联:ADR-0001(产品范围)、需求池 §5

## 背景

产品负责人在决策评审中选择支付方式为"微信和支付宝"。支付方式由分发渠道决定:iOS App Store 对虚拟商品强制 IAP(抽成 30%/15%),小程序 iOS 端虚拟支付同样受限,H5/安卓则微信+支付宝畅通。结合 ADR-0001 的电商优先定位(商家客群活在微信生态),重新评估后确认:对标 APP 的 iOS-only 是 C 端创作者锚定,不适用于我们的商家客群。

## 决策

| 项 | 决策 | 说明 |
| --- | --- | --- |
| V1 流水线 | **营销短视频(带货/探店)优先** | 先打通基础设施+最快现金流;漫剧工作台 V2 |
| 免费层 | **缩水免费层** | 新用户免费 1 条 480P 带水印预览;按 Atlas Mini 价成本 ≈¥0.4/人 |
| 分发渠道 | **微信小程序(主)+ H5(充值兜底/落地页)** | Android APP 延后;iOS App Store 不做/延后 |
| 支付 | **微信支付(小程序内)+ 支付宝/微信 H5 支付(H5 兜底)** | iOS 用户在小程序内买积分受限 → 引导 H5 充值(行业常规) |
| 客户端技术栈 | **uni-app 或 Taro 一码编译小程序+H5**(二选一待搭档技术确认) | 为后续套壳 APP 留路 |
| 模型供应商 | **Atlas Cloud 优先(Seedance 2.0 Mini/Fast),火山引擎官方为备用渠道** | 适配层可切换;价格 Mini ≈$0.0113/秒、Fast ≈$0.027/秒(480P,较官方低约 52-68%) |
| 定价方式 | **成本推演定初价**:API 实价 × 3-5 倍毛利,失败退款率计入 | 搭档核价(含汇率/结算成本)后定档位 |
| 分工 | **产品负责人 = 后端/基础设施(INF+BIZ+适配层);搭档 = 客户端+流水线前端** | 接口契约由产品负责人定,搭档并行不被阻塞 |

## 后果

- 正面:无苹果税;小程序当天发版(免商店审核);商家在微信生态内触达/支付/分享顺滑;模型成本较官方低约 52-68%,免费层与定价空间更大。
- 负面/风险:
  1. **Atlas 为境外第三方平台**:美元结算、无国内发票、用户上传内容出境(深度合成/数据出境合规)、无国内 SLA——**规模化前必须做合规评审**;
  2. 小程序 AIGC 类目需要算法/生成式 AI 备案(COMP-02 本就要求,不是新增);
  3. iOS 用户充值有 H5 跳转摩擦;
  4. 上游价格波动(即梦一月三涨前车之鉴)→ 定价含缓冲,月度对价。

## 护栏

1. **INF-04 模型适配层是 P0 中的 P0**:Atlas ↔ 火山引擎切换演练是 V0 验收项,供应商切换能力不是可选项;
2. 定价以"复核后 Atlas 实价 × 3 倍毛利"为底线,低于底线不出档;
3. iOS/APP 形态重议需新 ADR;
4. 月度对账:Atlas 账单 vs 成本账本(reconciled 字段,镜序 §10.8 模式)。

## 修订 v1.1(2026-10-02,小程序合规查证后):模型主通道由 Atlas 改回火山引擎

**触发证据**(小程序上线资质查证,见 `上线准备清单-资质与备案.md`):
1. 微信"深度合成"类目要求:使用第三方技术的,须提供**与技术提供方的合作协议(含算法名称/应用场景/备案编号,双方盖章)+ 模型备案号**;算法/协议主体必须与小程序主体一致。Atlas 为境外转售平台,无法稳定满足"盖章协议+国内备案编号"的材料链;
2. 网信办 2026-01 口径:通过 API 调用**已备案模型**的应用走地方网信部门"**登记**",无需 60 天自研备案——火山方舟的 Seedance 是已备案模型,登记路线最短;
3. 成本复核:我们主产品默认 720P(ADR-0001 护栏),Atlas 720P ≈$0.24/秒(≈¥1.72)与火山官方 ¥1.814/秒**几乎无差**;Atlas 的低价优势集中在 480P Mini 档(仅用于免费预览层)。

**修订决策**:模型主通道 = **火山引擎官方(合规登记链路 + 已备案模型)**;Atlas 降级为可选优化(免费层 480P 档,或合规评估通过后引入)。适配层可插拔要求不变(INF-04)。

## 修订 v1.2(2026-10-03):分阶段节奏——开发期 Atlas,上线期火山

**触发**:产品负责人补充关键信息——团队对 Atlas 作为模型供应商**已有实战经验**,且自有项目 2049-agent 中存在**现成的 Atlas 视频/图片适配器与积分计费设计**(见 `复用评估-2049agent.md`)。

**修订决策(时序化,不推翻 v1.1 的合规结论)**:
1. **V0/V1 开发期:Atlas 主通道**——适配器现成、团队熟悉、成本最低,端到端最快打通;火山适配器以 stub 形式存在于网关中;
2. **小程序"深度合成"类目提交前:火山接入完成**——拿到盖章协议+备案编号(登记材料硬要求),并用真实任务跑通;
3. **上线后:双通道常驻**——生产默认火山(合规),Atlas 承接免费预览层/成本优化;网关渠道池自动 failover。

**护栏**:两条通道的切换演练仍是 V0 验收硬项(INF-04);Atlas 仅用于开发与免费层,付费档位在上线前必须走火山(合规)。

## 修订 v1.3(2026-10-03):火山从第一天起为唯一主通道

**触发证据**(`技术确认会-证据包.md`):Atlas 官网博客自述其 API 目前仅提供 **Seedance v1.5 Pro/Fast,2.0 尚未开放**;而对标实测用的正是 2.0(S18),且火山 2.0-fast 480P 仅 ¥0.08/秒(5s ≈¥0.4/条,免费层成本被证实)、2.0 标准 ≈¥0.58/秒 @720p——**可得性 + 价格双因素下,Atlas 连"开发期主通道"都无法覆盖 2.0**。

**修订决策**:
1. **V0 起火山引擎为唯一主通道**:主力档 = Seedance 2.0-fast(480P,对标"基础版"),高档 = Seedance 2.0 标准(对标"专业版");企业实名+服务协议第 0 天发起;
2. Atlas 适配器移植为**备用渠道**(跑通 INF-04 切换演练即可),仅当需要 v1.5 家族低成本模型或非中国区域时启用;
3. 价格以控制台实时价为准(搜索快照已三角验证,比例关系可信,绝对值待核)。
