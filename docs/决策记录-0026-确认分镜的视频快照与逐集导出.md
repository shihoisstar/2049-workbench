# ADR-0026：确认分镜的视频快照与逐集导出

2026-10-11，负责人授权继续角色形象、逐镜视频、配音字幕与逐集导出，新增付费先确认。

当前失败路径：ADR-0023新分镜候选有plan_id且可以选图；旧视频入口只接受plan_id=null，旧导出查询也明确排除新分镜。因此新流程无法得到逐集文件。现有合成字幕为场号，且将所有输入音轨替换成静音，不能作为对白成片。

继续复用既有video job、submission、outbox、资产和export job，不建第二套媒体任务框架。新入口冻结已核对分镜、选定图片哈希、零至多个角色引用及对白原文；按当前内容与引用核对，报价单独确认，旧请求优先重放。新导出manifest版本2保留plan及镜头顺序、来源、对白和角色数组，不从可修改草稿临时拼合字幕。每集独立导出；缺失任一镜不得当作完整剧集。

本切片新视频仅显式开发模拟，测试积分和真实成本分开；新增付费0。配音处理支持经哈希核对的本地音轨及时间字幕，静音预览必须明确标识；没有真实TTS回执和声画验收，不称配音完成。营销与漫剧复用媒体字幕/音轨处理，商家事实和分类保持已有边界。

代价：视频任务新增一份不可变JSON快照、导出增加版本2分支和新入口；旧格式继续读取。普通用户批量制作、真正的图像/视频/TTS适配和完整5条高质量成片仍需后续实现与独立预算确认；不以5条模拟文件冒充目标完成。
