## 决策

2026-10-10负责人最新授权：AI自主拓展UI和原创视觉素材，可以使用GPT生图，不局限于同一张小猫飞船图片。保留整体视觉一致性与偏爱可爱幻想角色的方向，具体场景/角色/构图可自主设计；无需逐张索取设计稿。此授权面向产品UI素材，不自动续增业务文本、视频或TTS的既有限次付费评测。

完整功能与主要流程对标「AI漫剧创作神器」，主交付为微信小程序，覆盖普通创作者、已有剧本创作者和营销用途。墙外29张截图及历史操作记录作为行为依据；墙内流程可以借鉴CapCut、Vidu、可灵的公开官方流程，不要求购买对标会员，也不将推断冒充实测。

UI第二版采用负责人认可的新图方向：暖白底、粗黑中文标题、黑色控件、荧光黄绿重点色、作品大图与克制描边。替代UI-01原朱红主操作和旧参考板的视觉冻结约束。主要入口为漫剧/创作/我的，按微信导航和安全区适配；页面可重新组织，避免巨大的固定底部播放器和多个重叠操作栏。

负责人补充的视觉偏好：默认封面、灵感案例和创作示例优先使用小猫主角的电影感幻想冒险，例如橘猫驾驶飞船穿过粉色云海；不再以人类动漫角色作为默认展示方向。此项暂按产品展示偏好落实，不限制用户创作人物、其他动物或营销题材。补充参考见`UI参考图/v2-2026-10-10/03-小猫幻想创作参考.png`。

先做首页与双模式创建的可点击设计样稿，负责人核对后逐步迁入Taro真实页面。样稿中的示例内容与生产能力明确区分，不改变报价、钱包和实际受理开关。不建设独立生产H5工程，不将整张UI图贴成页面。

创作默认先确认剧本和角色形象，再自动制作；允许只修改不满意的镜头，保留原成果。是否保留单独的镜头检查页由实际任务需要决定，不先承诺或扩建专业分镜工作台/多轨编辑器。

首个完整质量样片目标为60–120秒、9:16、1080P、有清楚配音及准确字幕，检查人物一致性、动作异常与衔接。质量档与省钱档先报价后确认，不超过已确认费用上限。15分钟为首次成片的待实测体验目标，不是既有性能承诺；用户可离开后恢复查看。点赞作为真实试用反馈，不作交付保证。

技术失败按既有语义退款，未知受理按ADR-0007处置。生成成功但审美不满意的重做先报价后确认。成片保存微信相册后由用户自己上传抖音，本期不因此新增抖音账号绑定与直接发布。

## 授权边界与代价

负责人授权AI做设计和常规开发，不构成真实付费供应商试验、订阅定价、TTS费用或Git提交的新增授权。对应方案与成本测得后再确认。

可点击样稿先解决视觉与操作组织，代价是后续需映射到真实状态和Taro组件；不将样稿当成业务交付。采用现有Taro/React、contracts、server、Temporal与媒体能力，优先复用成熟组件/接口，不为每个页面新建框架。完整功能按REBUILD-01依赖顺序交付，正式商用前验收全部公开承诺能力，小批试用明确开放范围。

## 验收

设计稿对齐已证实的双模式字段、项目/剧本/同款入口与账户能力，未知能力单独标注。首页首屏可找到创建与剧本，创建页可切换模式、选择风格与参数，实际页面使用真实余额/报价/作业状态，微信触控和安全区单独验收。真实供应商、音频、真机与生产上线不由视觉验收替代。
