# ADR-0034：正式原声营销服务与报价绑定

2026-10-11。负责人要求继续正式生成服务和费用报价，AI漫剧/营销双业务均保留；交互简单、省成本，新增付费调用先确认。本轮编写正式接入代码和配置说明，不开启付费、不新增调用、不部署。

## 已确认的差距与做法

ADR-0033的持久媒体链已用已有样片走通，但10秒任务仍固定mock；旧渠道按5秒/分辨率选模型，不能将其直接用于已认可的Seedance 2.0 Fast原声短片。复用已有供应商提交权、账本、outbox和媒体工作流，单独绑定原生模型配置；不另建任务/计费框架。新增维护面为一个模型绑定函数、一个任务绑定字段和显式配置，新增故障面是API与worker配置不一致时需要运营核对，代价优于误换模型后自动重发。

## 正式营销报价与受理

- `NativeMarketingOffer`必须有安全正整数积分价及SHA-256模型绑定；未配置仍返回disabled及空价格，不用0冒充免费。mock入口保留原7测试积分语义。
- 绑定包含Atlas地址、固定T2V/参考图模型、10秒/720P/9:16、原声开启、高码率及提示词版本；报价另绑定本人、输入、素材顺序/哈希/有效期、原始商家事实与售价。材料尺寸和比例按本轮读取的官方参数，临近5分钟过期的素材提前拒绝。
- 接收时将模型绑定、模型、售价、内容一同持久保存；同原请求优先重放，不因开关关闭或报价改变新建作业。新请求必须匹配新报价。
- `0031_outgoing_kat_farrell.sql`新增native_binding并分别约束旧5秒、10秒mock、10秒Atlas。仅生成并读回，尚未应用任何数据库。
- worker新增独立原声渠道，和旧视频渠道分开配置；仍使用现有Atlas适配器。API/worker绑定或模型不匹配时，在取得提交权前停止。真实任务不能降级为mock；绑定中途改变，原回执轮询停止核对。
- 请求明确带generate_audio=true及bitrate_mode=high，并使用自然标准普通话女声、连续角色/物品、不虚构商家事实、不在画面生成字幕的提示词。网关单渠道、maxAttempts=1；持久提交权阻止重复POST。字幕与合成继续复用原片，不新收制作积分。
- 原生worker启用时必须有媒体队列和私有存储。媒体ASR模型与服务器准备仍须单独部署核对，不能仅设置API开关就认定可上线。

## 双业务费用交互

营销确认页说明本条费用包含原声、字幕核对和成片；重生成画面需重新确认。10秒模式也可免费检查口播时长，修复此前仅5秒模式提供提示的问题。

漫剧使用既有真实分集批次报价，页面改为明确展示“待生成集数 × 单集剧本价 = 本次剧本总价”，标明已有稿件保留、避免重复收费。制作计划明确交付目标为所选集数对应的独立视频，未接齐的全片费用不编造。此改动不代表角色/逐镜视频/配音都已有正式报价，更不代表五集成片已交付。

## 本轮成本证据

公开模型页本轮读取的起价仍为$0.027；原有两条720P、10秒原生音画样片回执各$0.5830272。公开起价不是本配置账户实扣；不能拿$0.27直接当10秒成本。模型页还说明高码率不改变token成本，因此保留已认可样片的high设置，不以降低码率节省不存在的模型成本。

来源：[Atlas T2V](https://www.atlascloud.ai/models/bytedance/seedance-2.0-fast/text-to-video)、[Atlas参考图视频](https://www.atlascloud.ai/models/bytedance/seedance-2.0-fast/reference-to-video)；实际回执沿用NATIVE-VISIT/NATIVE-COMMERCE留档。网页抓取仅访问公开页面，未提交生成请求。

项目现有定价文件采用“1积分=0.01元、换算系数6.8、成本两倍”的旧决策。用本次样片回执代入得到793积分（向上取整），只作历史政策下的试算，**不是已确认的新售价、实时汇率或保证毛利**；还需对账与计算本地计算/存储成本。新服务不自动使用该试算或旧368积分档。

## 启用配置（本轮未设置）

API：`API_NATIVE_MARKETING_ENABLED=1`、明确的`NATIVE_MARKETING_CREDITS`、`ATLAS_BASE_URL`。worker：`NATIVE_MARKETING_PROVIDER_MODE=atlas`、本机安全配置的`ATLAS_API_KEY`、同一`ATLAS_BASE_URL`、`TEMPORAL_MEDIA_TASK_QUEUE`及S3配置。媒体worker：已有`NATIVE_ASR_PYTHON`/`NATIVE_ASR_SCRIPT`/`NATIVE_ASR_MODEL_DIR`、字体和S3配置。默认不设上述启用开关，保持关闭。

剧本与营销文案沿用各自既有显式模型、价格和启用配置，不受原生视频开关控制。不得用营销报价替代漫剧整片报价，不将模型成本未知写成0。
