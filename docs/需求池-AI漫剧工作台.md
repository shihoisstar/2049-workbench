## 3. MVP 提案(待评审)

### V0 基础设施骨架(两流水线共用,约 2-3 周)
INF-01 ~ INF-06 + COMP-01。验收剧本:后台创建积分账户 → 调适配层生成一条 5s 测试视频 → 账本记录估算/实扣 → 模拟失败任务积分即时回账 → 导出文件含 AI 标识。

### V1 营销短视频 MVP(带货+探店,约 3-4 周)
MKV-01~04、06 + BIZ-01/02/04。**验收剧本(业务评审用,导师:验收标准=需求文档)**:
> 新商家注册 → 绑手机 → 选「剧情带货」→ 传商品图 → 输入卖点 → AI 文案生成 → 违禁词通过 → 选 720P → 看到积分估算 → 确认生成 → 进度可见 → 下载带水印+AI标识的视频;**若生成失败 → 积分即时回账 + 原因可见 + 可一键重试**;积分不足 → 弹充值(档位透明)。

### V2 漫剧工作台 MVP(约 4-6 周,含 DRAMA-04 预研)
DRAMA-01~07 + DRAMA-08(P1)。验收剧本:想法输入 → 剧本生成 → 角色/场景确认 → 分镜生成 → 逐镜头生成(失败只重做单镜头)→ 合成导出一集 60-120s 成片。

### V1 明确不做清单(防止范围蔓延)
模板市场/创作同款、会员优先队列、AI绘画/改图、数据分析看板、多语言、分销、漫剧流水线(排 V2)。
