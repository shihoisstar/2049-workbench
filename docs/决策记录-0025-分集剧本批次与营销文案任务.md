# ADR-0025：分集剧本批次与营销文案任务

2026-10-11，承接负责人继续多集自动生成、营销真实文案，5集最终5条成片、简单和省成本的授权。

单集任务及提示词固定第1集；前端循环不能证明批量费用已授权，也无法在离开后保证续作。营销没有新架构真实文案任务。长剧本一次POST存在既往输出截断证据；7次文本评测授权已用完，不能用开发授权扩大付费调用。

- 新增薄剧本批次记录，复用现有单集任务、outbox、一次POST权、回执和逐集账本。一次报价覆盖剩余集数，受理原子预留各集费用，后台串行制作，成功后原子激活下一集及汇总版本。已有可用剧本复用并进入报价指纹。
- 未知受理等待原任务核对；明确失败/格式问题停止后续并退还未启动集数预留。成功稿和可修复稿均保留，续作重新明确报价，只补缺失内容。
- 每次请求只输出指定一集，冻结故事输入、前文和角色名称，限制单集及汇总字数。角色/分镜仍需确认，剧本批次完成不算视频完成。
- 营销文案为有归属、报价、持久任务、一次提交与失败退款的文本任务，复用文本网关和回执规范；带货与探店分开处理，保留原资料，建议需用户采用后才填入视频描述。
- 真实批次与文案分别默认关闭，有明确价格才受理。隔离验证mock/注入供应商，新增付费0；真实质量评测准备完成后单独确认调用范围及预算。

代价：增加批次/文案持久字段、报价指纹与恢复检查。串行等待较长，但降低峰值并提供续作上下文。不新增通用调度框架，保留旧单集workflow控制流；新增营销文本workflow须独占运行和history验收。付费墙后交互为我们的设计。仍需真实画面/视频/音频及双方微信相册，最终验收完整5集和两种营销成片。

负责人后续明确回答“1，但是尽可能降低成本”：批准新增最多7次真实文本（5集剧本+带货/探店各1次），累计最多14次，人民币总预算仍不超过20元，程序累计保守估价限制$0.10，未知不自动重发。该授权不包含图片、视频或配音调用，不放开生产受理；执行结果另记。

执行7次/累计14次已用完：第四集超900暂停，免费编辑后复用1–4集，仅补第5集；带货“超软”未有资料支持。保持字数硬限，收紧新分集提示字符目标与材质承诺检查（需肯定原文引用，否定/未知资料不能支持），不原地修改旧回执、版本或成功任务；免费重放原带货回执失败退款。累计用量估价$0.0163752、实际扣款未知。完整自动五集质量和新版带货模型输出仍待新的授权评测，详见SERIES-COPY留档。
