# ADR-0014 剧本输出回执与失败用量保留

- 日期：2026-10-10。
- 状态：按持续开发授权实施；不扩大付费评测次数或开放真实收费。

首轮真实文本评测出现空正文和截断正文。现有chat适配器抛错时未保留规范化usage，router.chat还会捕获retryable=false错误继续尝试，可能造成多次付费；现有剧本作业只存成功版本或failureCode，不能追溯失败输出的用量。

修正现有chat入口：请求完整正文时只允许一次上游尝试，禁止因空正文、截断或未知响应自动换渠道重发；规范化回执携带provider/model/responseId/finishReason/有界正文及usage，错误亦携带回执。缺失用量为null，不估作0，不把token估算伪装成实扣金额。

剧本作业增加私有response字段。保存回执、判定输出及作业终态在一个事务中完成；相同回执重放只产生一个版本，不同回执冲突。截断、空输出、过长输出不成为可确认剧本；格式错误但完整的文本仍沿既有修复路径。回执仅内部本人范围查询，不加入公开job响应。

当前受理仍是mock，回执provider必须与该模式匹配。真实provider绑定、提交前持久记录与未知受理处置、报价/计费和真实质量复测仍须完成后才开放真实模型worker。新增成本为一个JSONB列和规范化字段维护，不引入新队列或任务框架。
