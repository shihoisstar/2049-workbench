# ADR-0013 剧本模拟作业与确认边界

- 日期：2026-10-10。
- 状态：依据负责人继续开发授权实施；真实模型与收费未授权。

2026-10-10授权补记：负责人已授权现有文本模型账户首轮3样例、最多4请求、总额20元人民币，并要求尽可能省成本；不扩大到生图/视频/TTS或公开收费。4次已执行，usage按单价计算$0.0076974、实扣未知；该轮额度不会自动续用。质量/截断问题见真实文本评测方案。原mock与公开受理边界保持。

随后负责人明确选择“允许，累计最多7次”，20元总预算不变。新增3次已完成，累计usage估价$0.0106572、实扣未知；7次已用完。仍只限文本评测，未授权生图/视频/TTS或公开收费。费用与质量结论见RESPONSE-AND-PARSER留档。

DRAMA-02先建设持久作业、输入快照、Temporal执行、不可变草稿版本与人工确认。复用现有PostgreSQL事务、outbox租约、解析器和项目模型，不新建任务框架。

当前只有明确标注的mock开发模式，默认HTTP受理关闭，通过独立开发开关开放；不调用模型、不预留积分、不写账本。mock生成一集固定结构示例，引用想法作为背景，不能声称理解用户想法或完成1–40集生成。失败保持原项目与旧版本。真实模型、输出上限和计价冻结后另行实施。

作业创建保存输入与outbox同事务；请求键按用户唯一，不同项目复用冲突；同项目最多一个accepted作业。输出先成为草稿，不自动覆盖项目固定版本；确认要求本人归属、解析成功和对应项目来源，确认后绑定不可变版本。已确认项目不由生成重试覆盖。

完成标准：契约/服务端/worker/小程序可编译；mock实际运行、幂等、失败、归属、确认和恢复需独立验收后才可声明闭环完成。真实供应商、真机与付费验收分开。
